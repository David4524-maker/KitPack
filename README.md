# Kitpack

KitPack se divide en 3 partes; KitDocu - La app de documentos. KitCalc- La app para hojas de calculo y KitPoint - la app de presentaciones

## *caracteristicas*

- 10 IDIOMAS

- Exportacion .html (EN KitDocu)

- Exportacion JSON (En KitPoint)

- Exportacion de 7 FORMAS (En KitCalc)
